# 资料

外部参考资料：面经、官方文档摘录、别人的文章。**二手信息，不是我的实测。**

写新条目之前，会拿条目的关键词 grep 一遍这个目录；命中就在条目里加一节 `## 与资料的关联`，写清对上了哪一点、和我的实测一致还是有出入。

**这里的东西一律不能写成事实。** 写法是「资料说 X」，不是「X」—— 带出处的错误比没出处的更可信，所以这里的污染更严重。

## 怎么往里放

用 `/incident-resource <文件>`（要装 `dsh-incident-journal`）。它先要出处，**要不到就拒收**；同一来源第二次注入走加厚，不新建。
